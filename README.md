# KISS's Law — Keep Integrity & Steady State

> A structured framework for AI causal reasoning and decision validation

KISS's Law transforms causal principles into executable rules for AI systems. It provides a rigorous methodology for auditing and projecting decisions through a verifiable causal chain.

## Quick Start

You don't need to understand the theory. Simply:

1. **Send the diagrams to your AI**
2. **Instruct it to follow the rules shown**
3. **Evaluate the results yourself**

## Key Variables

| Symbol | Name | Function |
|--------|------|----------|
| **R** | Domain Constant | Rigid boundary defining the operational domain |
| **S** | Steady-state Reserve | Minimum value across all subsystems |
| **D** | Perturbation | Maximum disturbance across all perturbation sources |
| **H** | Lever | Observable action intensity (subjective choice) |
| **M** | Steady-state Outcome | Auditable and projectable result |

**Core Formula:**  
```
M = (R × S) / (D × H)
```

## Core Principles

1. **No Skipping**: The causal chain R→S→D→H→M cannot be bypassed
2. **No Reversal**: The sequence order is fixed and immutable
3. **No Discontinuity**: Every link in the chain must maintain causal connectivity
